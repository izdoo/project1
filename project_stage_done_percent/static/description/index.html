Project Task Stage -> Done % (Gantt)

Cấu hình Done % theo giai đoạn để đồng bộ tiến độ chuẩn giữa Odoo và Gantt

Module giúp team PM chuẩn hóa quy tắc hoàn thành task: khi task ở trạng thái Hoàn tất, Done % sẽ tự cập nhật theo cấu hình trên từng stage.

Tính năng chính

Thêm trường cấu hình trên stage: Done % when task is completed (this stage).

Tự set percent_done khi task chuyển sang trạng thái Done.

Đồng bộ nhất quán dữ liệu tiến độ hiển thị trên backend và Bryntum Gantt.

  • Giá trị hỗ trợ: 0..100
  • Không phá quy trình nhập tay Done % hiện có
  • Triển khai nhanh, dễ training người dùng

Hướng dẫn sử dụng

  1. Vào Project -> Configuration -> Task Stages.
  2. Mở stage cần cấu hình và nhập Done % mục tiêu.
  3. Vận hành task như bình thường, khi trạng thái Done hệ thống tự cập nhật Done %.
  4. Mở Gantt để kiểm tra tiến độ hiển thị đồng bộ.

Khuyến nghị triển khai

Nên chốt chuẩn Done % theo stage với PMO trước khi áp dụng diện rộng (ví dụ Plan=0, Workshop=30, Review=80, Release=100).
